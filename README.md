# Gupta Ecommerce Sales Dashboard

## 📊 Project Overview
The Gupta Ecommerce Sales Dashboard presents key ecommerce performance indicators in a visual format. It helps users understand sales performance, quantity sold, profitability, and average order value.

## 📌 Key Performance Indicators (KPIs)
- **Total Sales:** 438K
- **Total Quantity:** 5,615
- **Total Profit:** 37K
- **Average Order Value:** 121

## 📈 Dashboard Features
- Quarterly filters (Qtr 1, Qtr 2, Qtr 3, Qtr 4)
- State filter
- KPI cards for essential business metrics
- Visual summary of ecommerce sales performance

## 🛠️ Tools
- Power BI (if used to create the dashboard)
- Data visualization and business intelligence
